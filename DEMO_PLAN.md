## Recording setup

- Use 1920×1080 desktop capture and a visibly readable cursor. Record the application, not unrelated tabs, notifications or private messages.
- Use our own Twitch test broadcast or footage with explicit permission. Keep other channels' copyrighted gameplay, music and personal content out of the final cut. Confirm permission for visible third-party marks/materials as well.
- Use the actual official embedded Twitch player playing live video; a thumbnail or frozen poster does not prove playback. Record one uninterrupted watch/play segment.
- Keep broadcast sound and game sound muted for the base cut. Captions make it understandable without sound. Optional music must be original or appropriately licensed.
- Put one short caption at a time in a reserved lower band, with strong contrast and enough reading time. Do not cover the player controls or the game action.
- Record real behavior. Normal cuts are fine; never edit a static concept to imply working gameplay or fake a passing test.
- Capture actual Codex work and results with secrets, account details and unrelated conversations excluded. Preserve a relevant real prompt and its resulting change.

## Capture list

3. Clean run with all three movement actions and tokens.
4. Pause on focus change and explicit resume.
5. App fullscreen entry and exit with the same retained run.

7. Actual Codex implementation exchange; renderer/simulation separation; real 21-test result.
8. Brief honest library shot, if retained.

## Before recording

- Push a reproducible repository and confirm its destination and visibility.
- Test install/build from a fresh checkout. Verify live playback on whichever host is shown; configure real metadata credentials if metadata will be demonstrated.
- Resolve the product assessment's highest-priority issues. Do not add unbuilt features to the script.
- Replace the repository placeholder. Confirm the correct implementation chat ID for the submission.
- Export at approximately 2:30, add English captions, and review the entire final video with sound off.
- Follow the official rules' public YouTube requirement; the FAQ's unlisted allowance conflicts, so public is the conservative choice. Upload and submission remain separate user-authorized steps.
